# Security policy

## Supported versions

Security fixes are applied to the current `main` branch. Deployments should use
the latest reviewed commit and digest-pinned images from that branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
advisory flow for this repository:

https://github.com/krbob/docker-invision-community/security/advisories/new

Include the affected commit or image, impact, reproduction steps, and any safe
mitigation you identified. Please do not include credentials, backups, or
personal data. A report will be acknowledged as soon as practical and a fix or
mitigation will be coordinated privately before disclosure.

## Scope

This policy covers the Compose configuration, Dockerfiles, scripts, and
documentation in this repository. Invision Community itself and third-party
container images have their own security channels.
